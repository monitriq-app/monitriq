- Available card: p-3; the title may wrap (leading-tight) with the status dot top-aligned; the per-currency stack drops the redundant currency label above the amount (the amount already carries its code) and puts the code inside the chip row only for currencies with no amount (Needs setup); currency blocks are separated by a thin divider instead of large gaps; the "Set amount to keep" link is visually compact (h-7) with a ::before hit area that keeps a 48px effective target; the disclosure in this tile uses a short label ("How it's worked out" / "See the calculation") so it stays on one line, and no longer repeats the currency code (each block already sits under its own amount). - Two-card row: grid-cols-2 -> content-weighted columns (1fr : 1.25fr) with an 8px gap, so the tile with the long explanatory sentences gets more width and wraps fewer lines. - "Can I afford this?": padding p-4 -> px-4 py-[1.125rem], icon 36px -> 40px (glyph 18 -> 20), title text-sm -> text-[15px], thin teal-tinted border (existing accent token at 25%) for presence; icon, title, copy and chevron are unchanged, 48px minimum kept. No gradient, glow, blur or shadow.

Shared classes only; no per-language or per-state overrides.
